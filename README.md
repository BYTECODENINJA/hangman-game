Hangman Game
A fun, interactive web-based Hangman game built with vanilla HTML, CSS, and JavaScript. Challenge yourself to guess words from themed categories while avoiding drawing a complete hangman figure. Features include a visual keyboard, hint system, and responsive design for all devices.

🎮 Features
Dynamic Word Display: Underscores reveal letters as you guess correctly, showing progress in real-time.
Interactive Keyboard: Click or type letters on a color-coded keyboard (green for correct, red for wrong). Used letters are disabled to prevent repeats.
Hangman Drawing: SVG-based hangman that builds with each incorrect guess—6 chances to win!
Hint System: Limited to 3 hints per game; reveals a random unguessed letter and fills it into the word placeholders instantly.
Categories & Random Selection: Words randomly chosen from categories like Animals, Countries, and Fruits for variety.
Responsive Design: Optimized for desktop, tablet, and mobile—buttons stack vertically on smaller screens.
Game Logic: Win by guessing the full word or lose when the hangman is complete. Reset for a new game anytime.
Keyboard Support: Type letters directly on your physical keyboard for faster play.
🚀 How to Play
The game selects a random word and category (e.g., "Animals").
Guess letters by clicking the on-screen keyboard or typing on your keyboard.
Correct guesses fill in the word placeholders; incorrect ones draw parts of the hangman.
Use hints (up to 3) if you're stuck—they reveal a letter and update the display.
Win by completing the word before running out of guesses, or lose when the hangman is fully drawn.
🛠️ Installation & Setup
No installation required! This is a pure client-side web app.

Clone or download this repository.
Open index.html in any modern web browser (Chrome, Firefox, Safari, etc.).
Start playing immediately—no server or dependencies needed.
File Structure
index.html: Main HTML file with game structure.
style.css: CSS for styling and responsiveness.
script.js: JavaScript for game logic, hints, and interactions.
🖥️ Technologies Used
HTML5: Structure and SVG for hangman drawing.
CSS3: Styling, animations, and responsive design.
JavaScript (ES6+): Game logic, event handling, and DOM manipulation.
